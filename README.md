# IPL API Consumer

A simple Flask application that consumes an IPL API and provides features such as displaying IPL teams in dropdown lists and viewing related team information.

## Technologies

* Python
* Flask
* Requests
* HTML
* CSS

## Features

* Fetch IPL team data from an API
* Display teams in dropdowns
* Render data using Jinja2 templates

## Run

```bash
pip install -r requirements.txt
python app.py
```

Open:

```
http://localhost:6000
```
